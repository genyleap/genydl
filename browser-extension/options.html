GenyDL browser integration

GenyDL never intercepts downloads unless you enable an automatic mode. Right-click a link and select Download with GenyDL to review it first. The browser will ask for download-management permission only when you enable Ask or Always.

Always mode requires your explicit choice. Authenticated, POST, and stream-backed downloads may fail outside the browser. GenyDL asks for browser permissions using the browser's normal UI; it does not silently install extensions.
