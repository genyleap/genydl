Browser download integration

Download behavior

Manual mode leaves ordinary downloads in your browser. Right-click a link or send it from the toolbar to review it in GenyDL.

Ask and Always request the browser's download-management permission. You can return to Manual at any time.

Automatic capture rules

One hostname per line. Rules apply to Ask and Always. Authenticated, POST and stream-backed downloads may need to remain in the browser.
