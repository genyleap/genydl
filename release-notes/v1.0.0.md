# GenyDL v1.0.0 — First Release 🚀

The first milestone release of **GenyDL** — a next-gen, ultra-fast, and reliable download manager built with **C++23**, **Qt 6**, and **QML**.

This release establishes the desktop experience: the QML interface, the core download workflow, cross-platform packaging, and the runtime foundation that everything else will build on.

## ✨ Highlights

- **Modern QML desktop interface** — clean, responsive, dark-mode UI
- **Multi-segment download engine** — segmented HTTP transfers with resume, pause, retry, cancel, and remove
- **Torrent & magnet support** — BitTorrent backend for P2P downloads
- **IPFS & Geny ecosystem integration** — decentralized networking foundation
- **Built-in Release Center** — track GitHub apps and update them in place
- **Queues & categories** — organize downloads by Videos, Music, Images, Documents, Archives, OS images, Games, Torrents, NFTs, and more
- **Per-segment progress** and a detailed download-info window
- **Drag-and-drop add** — drop a link, magnet, or `.torrent` straight into the app
- **Runtime dashboard** — live speed, transfer, CPU, memory, disk, network, and power status
- **Self-update client** — platform- and architecture-aware, with URL probe and GitHub/IPFS resolution
- **Session persistence** with import/export and post-download action foundations
