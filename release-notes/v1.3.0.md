# GenyDL v1.3.0 — Browser Integration and Download Reliability

This release builds on v1.2.200 with native browser integration, resilient HTTP downloads, runtime localization fixes, and refinements to the desktop settings experience.

## Browser integration

- Dedicated browser connection settings for Firefox, Google Chrome, and Opera, with browser icons, independent enable switches, and connection indicators based on recent native messaging responses.
- Firefox add-on available on [Mozilla Add-ons](https://addons.mozilla.org/en-US/firefox/addon/genydl-download-with-genydl/). The extension has its own version (1.3.3).
- Chrome and Opera unpacked extensions can be exported from the installed desktop application via Configuration → Browsers. Their store listings are not yet published.
- Manual link review remains the default; optional automatic capture requires user permission.
- Native Messaging is handled by the GenyDL executable itself. Compatibility with the published Firefox 0.1.1 protocol is retained.
- Refreshed extension popup, original GenyDL icons, and light/dark theme support.

## Updater reliability

- Prevent repeated update checks and download requests from interrupting an active update.
- Correctly distinguish downloading, verifying, cancellation and completion; retain the verified installer when reopening Updates.
- Clean up incomplete files on cancellation or write failure.
- All six targets are rebuilt from the same corrected source commit. If you already installed the earlier v1.3.0 build, reinstall this replacement manually because the version number is unchanged.

## Download reliability

- Improved recovery from interrupted segmented HTTP transfers.
- Improved recovery of incomplete partial files.
- Prevent HTTP error-response bodies from contaminating resumable download data.
- Fixed downloader and C++ module compilation issues.

## Localization and desktop UI

- Added 280 translations across Persian, Arabic, German, Spanish, French, Russian, Turkish, and Simplified Chinese.
- C++ status-label bindings now participate in live QML retranslation, including IPFS gateway health and download states.
- Improved RTL switch geometry and translated settings-tab sizing.
- Browser settings scroll vertically only, with content constrained to the viewport.
- Fixed invalid cursor-shape assignment in AlphaGlass.

## Downloads and installation

Select the package for your operating system and architecture from the release assets once the release build completes.

| OS | Architectures |
| --- | --- |
| macOS | Apple Silicon (arm64), Intel (x86_64) |
| Windows | x64, ARM64 |
| Linux | x86_64, ARM64 (AppImage) |

For browser setup, see the [browser integration guide](https://github.com/genyleap/genydl/blob/main/docs/browser-integration.md).

## Validation and known limitations

Linux x86_64 backend, native messaging, extension smoke tests, translation catalog checks, and isolated QML scroll regression tests were exercised during development. The maintainer verified Firefox connectivity and browser settings on macOS. Real Chrome and Opera browser integration and the final cross-platform packages still require runtime validation. Opera store submission is currently blocked by its developer-account registration error. BitTorrent functionality depends on whether libtorrent-rasterbar is available in the build; builds without it use the stub backend.
